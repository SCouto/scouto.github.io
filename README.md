### Running locally

This is a static site (vanilla HTML/CSS/JS, no build step). Serve it with Python's built-in server:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000 in your browser. Press `Ctrl+C` to stop.

Alternatively, open `index.html` directly in a browser, though some relative paths may not resolve under `file://`.
